## 🚀 Featured Projects

### 1. AutoOps — MCP-Based AI SRE Platform
**Tech Stack:** Java, Spring Boot, MCP, Kafka, Redis, Docker, Kubernetes, AWS, LLM, OpenTelemetry

A cloud-native agentic runtime platform that detects service failures, classifies incidents, plans remediation, executes approved tools, and validates recovery.

Key features:
- MCP-style remediation tools
- Multi-agent incident handling
- RBAC and approval gates
- Risk scoring and rollback checks
- OpenTelemetry-style tracing
- Audit logs, SLO tracking, MTTR analysis, and RCA reports

---

### 2. ReplayBench — AI Agent Evaluation Platform
**Tech Stack:** Java, Python, PostgreSQL, Kafka, Docker, LLM, Hibernate/JPA

A replay-based AI evaluation platform for benchmarking agent decisions across distributed-system failure scenarios.

Key features:
- Agent decision replay
- A/B testing for rule-based, LLM-based, and hybrid agents
- Regression testing after prompt/model/policy changes
- Accuracy, latency, MTTR, safety score, and recovery success metrics
- PostgreSQL persistence for scenarios, traces, and benchmark reports

---

### 3. Pulse — SLO-Aware Telemetry and Causal RCA Pipeline
**Tech Stack:** Java, Kafka, Redis, PostgreSQL, Docker, Grafana, OpenTelemetry, AWS

A Kafka-based observability pipeline for processing logs, metrics, traces, and service events to detect reliability issues in distributed systems.

Key features:
- SLO burn-rate alerting
- Latency spike and error burst detection
- Kafka lag and dependency degradation analysis
- Causal root-cause analysis
- Grafana dashboards and incident timelines

---

### 4. GateKeeper — Multi-Tenant Adaptive API Gateway
**Tech Stack:** Java, Spring Boot, Redis, Docker, Kubernetes, AWS, OpenTelemetry, REST APIs

A distributed API gateway designed to protect backend services from traffic spikes, abuse, and downstream failures.

Key features:
- Token Bucket and Sliding Window rate limiting
- Redis Lua-based atomic counters
- Multi-tenant quota management
- Adaptive throttling and backpressure
- Circuit breakers and brownout-mode load shedding
- Request tracing and audit logs

---

### 5. Real-Time Ride Matching Platform
**Tech Stack:** Java, Spring Boot, H2, Docker, REST APIs, Geospatial Matching

A backend system that simulates Uber/Ola-style ride matching using driver proximity, availability, load-aware assignment, dynamic pricing, and event logs.

Key features:
- Ride request matching API
- Driver location update API
- Haversine distance calculation
- Dynamic pricing / surge multiplier
- Driver reject and rematch flow
- Dashboard metrics

---

### 6. Distributed Job Scheduling System
**Tech Stack:** Java, Spring Boot, H2, Docker, REST APIs, Scheduling, Event Logs

A distributed job scheduling simulation for background task execution with retries, locking, worker execution, and dead-letter handling.

Key features:
- Job submission and status APIs
- Worker execution loop
- Retry with exponential backoff
- Dead Letter Queue behavior
- Distributed lock simulation
- Leader election simulation
- Priority-based job dispatching
